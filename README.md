## 現行の計算モデル

Pは送料を除くUSD商品価格、Jは税込仕入価格（円）、XはUSD/JPY TTMです。

```text
買い手送料 S：P < 2500は送料表、P >= 2500は0（自動モード）
売上 R = (P + S) × X
手数料ベース B = (P + S) × 1.08
FVF = min(B, 2500) × 12.35% + max(0, B − 2500) × 2.35%
eBay手数料 E = (FVF + B×1.35% + B×広告料率 + 注文固定費) × 1.10
注文固定費 = (P + S) >= 10.01 ? $0.40 : $0
Payoneer = ((P + S) − E) × 2%
日本側送料 D：P < 800は¥4,000、P >= 800はROUND(4000 + max(2500, P×X×1.20%))
粗利 G = R − J − (E + Payoneer)×X − D − S×X
還付参考額 = J×10/110×還付率（適格100%／非適格70%）
還付込み利益 = G + 還付参考額
利益フロア F = max(5000, ROUND(J×3%))：G < Fなら警告
```

買い手送料と日本側送料は手動上書き可能です。送料表は各帯の上限以下で判定し、小数の価格帯にも対応します。$2,499を超えて$2,500未満は最後の$375帯です。

広告の既定は**手動2%**。任意の自動モードでは**3%で試算し、粗利率10%未満なら0%で再計算**します。既定は自動モードではありません。PL保険は計算対象外で、日本側発送の輸送保険とは別です。

## 主な機能

| 分類 | 実装済みの内容 |
|---|---|
| 利益表示 | 売上・費目明細・粗利・還付込み利益・利益率・コスト内訳・フロア警告 |
| 為替 | MURCの前営業日TTM、USD／EUR／GBP／CAD／AUD、GET `?id=YYMMDD`、最大10暦日の候補を遡及 |
| 取得失敗への対応 | 同じブラウザのlocalStorageに保存したTTMを、保存から7日以内なら再利用 |
| 仕入区分 | 適格請求書あり100%／非適格70%を選択。還付の計算基礎は仕入のみ |
| 比較 | 2件のライバル価格比較、5通貨の参考換算 |
| 保存・出力 | 同一ブラウザ内に最大10件の計算履歴、現在計算のUTF-8 BOM付きCSV |
| 操作・レイアウト | 通貨の3桁カンマ表示、PC2カラム／モバイル縦積み、手動上書き |

## 実装上の制約と注意

本書はユーザー確定の計算モデルを説明するもので、eBayの全カテゴリ・取引条件や税務適用を保証しません。非適格70%は現行アプリの固定設定で、取引日や制度改定による自動切替は未実装です。利益フロアは画面警告のみで、出品・監視の自動停止は行いません。

履歴とTTMキャッシュは端末間・ブラウザ間で同期しません。履歴には仕入区分・広告モード・為替・フロア判定を保存せず、入力再読み込みもありません。計算関数の送料境界は小数USDに対応しますが、メイン画面の商品価格入力は現行実装で整数として解析されます。これらは未実装機能を誤って仕様へ含めないための記録です。
