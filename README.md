## 2モードの違い

| 条件 | eBay（既定） | 海外直接取引 |
|---|---|---|
| `salesChannel` | `ebay` | `direct` |
| 発送方法 | CPASS | DHL直接契約 |
| 関税方式 | 商品価格$2,500未満DDP、以上DDU | 価格・配送先を問わず全商品DDU |
| 基本発送費 | ¥5,000 | 香港・シンガポール¥5,500、その他¥8,500 |
| 買い手請求送料S | 自動送料表またはeBay用手動値 | 独立した`directShippingUsd`、既定$0 |
| Sの扱い | 売上へ加算し、S×TTMを同額費用控除 | 売上へ加算。同額費用控除なし |
| 手数料 | eBay・広告・Payoneer | Wise／Revolut 1%、PayPal 5%の決済手数料のみ |
| 広告自動判定・ライバル比較 | 利用可 | 計算対象外・比較UI非表示 |

## 共通の計算モデル

Pは送料を除くUSD商品価格、Jは税込仕入価格（円）、XはUSD/JPY TTM、Sは買い手請求送料です。

```text
販売価格合計 T = P + S
売上 R = T × X
保険込発送費 D：P < 800は基本額、P >= 800はROUND(基本額 + max(2500, P×X×0.012))
粗利 G = R − J − 合計手数料（円） − D − 買い手送料の同額費用
還付参考額 Q = J×10/110×還付率（適格100%／非適格70%）
還付込み利益 N = G + Q
利益フロア F = max(5000, ROUND(J×3%))：G < Fなら警告
```

保険は**全発送方法で商品価格$800以上のみ**加算します。税込仕入価格や送料込み合計ではなくPの円換算が基準です。保険込送料は両モードで手動上書きでき、UIで販売モードを切り替えると自動計算へ戻ります。

### eBayの手数料

```text
手数料ベース B = T × 1.08
FVF = min(B, 2500) × 12.35% + max(0, B − 2500) × 2.35%
eBay手数料 E = (FVF + B×1.35% + B×広告料率 + 注文固定費) × 1.10
注文固定費 = T >= 10.01 ? $0.40 : $0
Payoneer = (T − E) × 2%
合計手数料（円） = (E + Payoneer) × X
買い手送料の同額費用 = S × X
```

送料自動モードはPが$2,500以上ならS=$0、未満は送料表の各上限以下で判定します。$2,499を超えて$2,500未満は最後の$375帯です。手動送料はDDUでも入力値を採用します。

広告の既定は**手動2%**。任意の自動モードは**3%で試算し、粗利率10%未満なら0%で一度再計算**します。PL保険は対象外で、発送に加える輸送保険とは別です。

### 直接取引の手数料

```text
決済手数料 = (P + directShippingUsd) × 決済料率
決済料率 = Wise 1% / Revolut 1% / PayPal 5%
合計手数料（円） = 決済手数料 × X
買い手送料の同額費用 = 0
```

直接取引ではSales Taxの上乗せをせず、FVF・国際手数料・Promoted Listings・固定費・eBay手数料消費税・Payoneerはすべて0です。適用広告率は0%、広告自動判定と広告停止フラグもfalseになります。eBay用の送料・広告入力が保持されていても直接計算には使いません。

## 主な機能と保存

| 分類 | 実装済みの内容 |
|---|---|
| 利益表示 | 売上・費目明細・粗利・還付込み利益・利益率・コスト内訳・フロア警告 |
| 為替 | MURCの前営業日TTM、USD／EUR／GBP／CAD／AUD、取得失敗時に保存から7日以内のキャッシュを再利用 |
| 比較・換算 | eBayは2件のライバル価格比較。5通貨の参考換算。直接取引の販売価格は請求送料込みで換算 |
| 履歴 | 同一ブラウザ内に最大10件。v1保存キー維持、旧履歴は「eBay（旧計算）」として保存時の結果を保持 |
| 新履歴項目 | 販売モード、直接決済方法・配送先、保険込送料、計算バージョン`2026-11-08` |
| CSV | 共通helperで現在の1件をUTF-8 BOM付きCSVへ。`overseas-profit-{channel}-YYYY-MM-DD.csv` |

履歴の完全な入力再読み込み・再計算は未実装です。為替・仕入区分・広告モード・フロア判定等の全入力は履歴に保存しません。履歴とTTMキャッシュの端末間同期もありません。

## 検算例

## 注意とGitHub更新運用

定数・式は**ユーザー確定の試算モデル**であり、法令の現況、実際の関税・手数料・還付資格を保証しません。非適格70%は固定値で、取引日別の自動切替はありません。利益フロアは画面警告だけで、出品や監視を自動停止しません。商品価格の通常入力は整数解釈、直接請求送料は小数2桁入力に対応します。

このリポジトリは**仕様・設計の文書保管先**です。Manus側のアプリ保存・公開とGitHub文書更新は別操作で、チェックポイント保存による自動同期はありません。現行アプリを確認し、仕様書・設計書・検算例・変更履歴を手動更新してレビューする運用を継続します。
