# eBay利益計算ロジック仕様書

> 作成日: 2026-03-19
> 最終更新: 2026-03-22（Manus版仕様書・設計書の内容を統合）
> 対象: 日本→米国を中心としたeBay越境販売の利益計算

---

## 1. 概要

デミニミスルール撤廃後の米国向けeBay越境販売において、**送料に関税相当額を上乗せ**して関税コストを回収する方式の利益計算ロジック。

### 方式の概要

- Shipping Chargeに関税分を加算
- 商品価格帯に応じた送料を設定（手動入力への切替も可能）
- 米ドル販売・$2,500未満はDDP（セラーが関税を事前支払い）
- GBP/EUR/CAD/AUD向けはDDU（バイヤー負担）

### 対象ユーザー

日本国内で商品を仕入れてeBay（米国マーケットプレイス）で販売する個人・法人の出品者。為替リスクの管理や複数通貨での価格設定を行う中級〜上級の出品者を主なターゲットとする。

## 2. 入力パラメータ

パラメータは **必須**・**推奨**・**固定** の3種に分類される。

### 2.1 必須パラメータ（ユーザーが必ず入力）

| パラメータ | 単位 | 説明 | 例 |
|-----------|------|------|-----|
| 商品価格 | USD ($) | eBay上の商品部分の価格（送料を除く） | 3,970 |
| 仕入価格 | JPY (¥) | 日本国内での仕入原価（消費税10%込み） | 450,000 |

> この2項目がなければ利益計算は実行不可。

### 2.2 推奨パラメータ（入力がなければデフォルト値を使用）

| パラメータ | 単位 | デフォルト値 | 説明 |
|-----------|------|------------|------|
| Promoted Listing率 | % | **3%** | 広告出稿率（最低2%以上、0%で非出稿） |
| 荷物分送料 | JPY (¥) | **¥3,000** | 実際の国際配送費用（EMS等） |
| FVF% | % | **12.35%** | Final Value Fee率（カテゴリ別）。カテゴリにより異なる場合は明示入力 |

> デフォルト値は標準的な販売条件を想定した保守的な値。商品カテゴリや配送条件が異なる場合は適宜変更を推奨。

### 2.3 固定パラメータ（システム値・変更不要）

| パラメータ | 固定値 | 説明 |
|-----------|--------|------|
| 為替レート (円/$) | 前営業日のTTM（API自動取得） | 三菱UFJ銀行公表の対顧客電信仲値（TTM）をAPIで取得（§2.6参照） |
| Sales Tax率 | 5% | 米国州売上税。（詳細パラメータとして変更可能） |
| 海外手数料% | 1.35% | International fee（eBay固定） |
| ペイオニア手数料% | 2% | Payoneer送金手数料（固定） |
| 送料 ($) | 送料早見表から自動決定 | 商品価格帯に応じた関税徴収用送料（手動入力モードへ切替可能） |

### 2.4 送料入力モード

関税徴収用送料の決定方法を切り替える。

| モード | 説明 |
|--------|------|
| **自動（早見表）** | 商品価格帯に応じて送料早見表（§4）から自動決定（デフォルト） |
| **手動入力** | ユーザーが任意の送料(USD)を直接入力 |

```
shippingFeeUsd = useAutoShipping
  ? SHIPPING_TABLE.find(r => itemPriceUsd in [r.minPrice, r.maxPrice]).shippingFee
  : manualShippingUsd
```

### 2.5 導出値（入力パラメータから自動計算）

| 項目 | 算出方法 |
|------|---------|
| 販売価格 ($) | 商品価格($) + 送料($) |
| 関税徴収用送料 (¥) | 送料($) × 為替レート |
| 送料合計 (¥) | 荷物分送料(¥) + 関税徴収用送料(¥) |

### 2.6 為替レート自動取得（TTM）

アプリ起動時に三菱UFJ銀行（三菱UFJリサーチ&コンサルティング）が公表する対顧客電信仲値（TTM）を自動取得する。

- **取得対象:** USD、EUR、GBP、CAD、AUD の5通貨
- **取得元:** [三菱UFJリサーチ&コンサルティング 外国為替相場](https://www.murc-kawasesouba.jp/fx/past/index.php)
- **取得タイミング:** ページ初回表示時に自動実行、「TTM再取得」ボタンで手動再取得可能
- **フォールバック:** 最大10営業日遡って取得を試みる（土日・祝日スキップ）
- **TTM計算式:** TTM = (TTS + TTB) ÷ 2（小数点以下2桁で四捨五入）
- **手動上書き:** 自動取得後もユーザーが各フィールドを手動で変更可能
- **通貨名マッピング（スクレイピング用）:**

| 通貨コード | HTML上の日本語表記 |
|---|---|
| USD | 米ドル |
| GBP | イギリスポンド |
| EUR | ユーロ |
| CAD | カナダドル |
| AUD | オーストラリア・ドル（中点あり） |

> **注意:** AUDの日本語表記は「オーストラリア**・**ドル」（中点あり）であり、「オーストラリアドル」（中点なし）ではない。正規表現マッチ時に注意が必要。

## 3. 利益計算ロジック（コア計算式）

### 3.1 売上額（円）

```
売上(¥) = (商品価格($) + 送料($)) × 為替レート
```

### 3.2 eBay手数料（FVF + 海外手数料 + PL）

eBayの手数料は **Sales Taxを含む注文合計額** に対して課される。

```
手数料ベース($) = (商品価格($) + 送料($)) × (1 + Sales Tax率)

FVF($)      = 手数料ベース × FVF%
海外手数料($) = 手数料ベース × 海外手数料%
PL手数料($)  = 手数料ベース × Promoted Listing率%

eBay手数料合計($) = FVF + 海外手数料 + PL手数料
```

### 3.3 ペイオニア手数料

ペイオニアの手数料は **eBay手数料控除後のネット受取額** に対して課される。

```
ネット受取額($) = (商品価格($) + 送料($)) − eBay手数料合計($)
ペイオニア手数料($) = ネット受取額($) × ペイオニア手数料%
```

> eBayがFVF等を差し引いた後の金額がPayoneerに送金され、Payoneerはその受取額に対して2%を徴収する。

### 3.4 合計手数料（円換算）

```
合計手数料(¥) = (eBay手数料合計($) + ペイオニア手数料($)) × 為替レート
```

### 3.5 送料（円）

```
送料合計(¥) = 荷物分送料(¥) + 関税徴収用送料(¥)
```

- **荷物分送料**: 実際の国際配送費用（日本円）
- **関税徴収用送料**: 関税回収のために上乗せした送料部分（送料早見表 or 手動入力で設定）

### 3.6 粗利額（円）

```
粗利額(¥) = 売上(¥) − 仕入価格(¥) − 合計手数料(¥) − 送料合計(¥)
```

### 3.7 粗利率

```
粗利率(%) = 粗利額(¥) / 売上(¥) × 100
```

### 3.8 消費税還付額

輸出売上は消費税が免税（0%）となるため、国内で支払った仕入税額（インプット消費税）の還付を受けられる。
還付対象は **国内で消費税を実際に支払ったコスト** のみ。

```
消費税還付額(¥) = 仕入価格(税込) × 10/110 + 荷物分送料(税込) × 10/110
```

> 仕入先がメルカリ・ヤフオク等の場合、表示価格＝税込価格のため `× 10/110` を使用。
> 仕入先から税抜価格で請求される場合（業者間取引等）は `仕入価格(税抜) × 10%` を使用。

#### 各コストの消費税区分

| コスト項目 | 消費税 | 還付対象 | 理由 |
|-----------|--------|---------|------|
| 仕入価格 | 含む（国内購入は税込） | **対象** | メルカリ・ヤフオク等は税込価格 |
| 荷物分送料（国内配送） | 含む | **対象** | 国内運送サービスは課税取引 |
| 国際送料（EMS等） | 含まない | 対象外 | 輸出関連は免税/非課税 |
| eBay手数料（FVF, Int'l, PL） | 含まない | 対象外 | 海外事業者からの役務提供 |
| ペイオニア手数料 | 含まない | 対象外 | 海外事業者からの役務提供 |
| 関税（DDP時の米国関税） | 含まない | 対象外 | 米国政府への支払い |

> **リバースチャージについて**: eBay・Payoneer等の海外事業者からの役務提供はB2Bリバースチャージの対象となり、消費税申告書上では申告・控除の両方に計上するが、相殺されるため **利益計算上のキャッシュインパクトはゼロ**。還付額の計算には含めない。

### 3.9 還付込み利益額・利益率

```
還付込み利益額(¥) = 粗利額(¥) + 消費税還付額(¥)
還付込み利益率(%) = 還付込み利益額(¥) / 売上(¥) × 100
```

### 3.10 DDPフラグの判定

```
isDdp = 商品価格($) < 2,500
```

- `true` → DDP: USD販売価格 = 商品価格 + 送料（関税込み）
- `false` → DDU: USD販売価格 = 商品価格のみ（関税バイヤー負担、送料$0）

## 4. 送料早見表ロジック（送料シート）

関税率は **15%固定**（日本原産品の相互関税率）。

### 算出ルール

```
送料($) = ROUND(価格帯上限($) × 15%)
```

- $50刻みの価格帯ごとに送料を設定（最初の帯のみ$0〜$100）

## 5. 多通貨対応ロジック

USD以外の通貨での販売価格も算出する。クロスレートはTTMから算出。

```
他通貨価格 = 商品価格($) × USD/JPY TTM ÷ XXX/JPY TTM
```

| 通貨 | 方式 | 出品価格の算出式 |
|------|------|---------------|
| USD ($) | DDP（$2,500未満）/ DDU（$2,500以上） | 商品価格 or 商品価格 + 送料 |
| EUR (€) | DDU | 商品価格($) × USD/JPY ÷ EUR/JPY |
| GBP (£) | DDU | 商品価格($) × USD/JPY ÷ GBP/JPY |
| CAD (C$) | DDU | 商品価格($) × USD/JPY ÷ CAD/JPY |
| AUD (A$) | DDU | 商品価格($) × USD/JPY ÷ AUD/JPY |

- USD向けのみDDP（関税セラー負担、$2,500未満）
- EUR/GBP/CAD/AUD向けはすべてDDU（関税バイヤー負担）のため、商品価格のみを換算

## 6. ライバル価格比較セクション

eBayのアイテム番号を入力することで、ライバル出品者の商品価格・送料をeBay Browse APIから自動取得し、自分の出品価格と比較表示する。

| 項目 | 説明 |
|------|------|
| 最大比較数 | 2件（ライバルA・ライバルB） |
| 入力方法 | eBayアイテム番号（数字のみ、最大20桁） |
| 取得情報 | 商品タイトル、商品価格（USD）、送料（USD） |
| 比較表示 | 自分・ライバルA・ライバルBの合計価格（商品価格 + 送料）を並列表示し、最安値を強調表示 |

### eBay Browse API連携

1. 環境変数 `EBAY_CLIENT_ID` / `EBAY_CLIENT_SECRET` を使用してOAuth 2.0 Client Credentials フローでアクセストークンを取得
2. トークンはメモリ内にキャッシュし、有効期限の1分前に再取得
3. `GET /buy/browse/v1/item/v1|{itemNumber}|0` でアイテム情報を取得
4. 404の場合は `GET /buy/browse/v1/item/get_item_by_legacy_id?legacy_item_id={itemNumber}` にフォールバック
5. レスポンスから `title`、`price.value`、`shippingOptions[0].shippingCost.value` を抽出して返す

## 7. リセット機能

ヘッダーの「リセット」ボタンにより、すべての入力値をデフォルト値に戻す。為替レートはデフォルト値（暫定値）に戻るため、TTMを再取得する必要がある。

## 8. 手数料率一覧

| 手数料 | 率 | 計算ベース | 備考 |
|--------|-----|-----------|------|
| FVF (Final Value Fee) | カテゴリ別（12.35%/13.25%等） | (販売価格+送料) × (1+SalesTax率) | eBayカテゴリにより変動 |

## 10. 非機能要件

### 10.1 パフォーマンス

商品価格・仕入価格の入力変更に対して、計算結果はリアルタイム（入力のたびに即時）で更新される。TTM取得は非同期で行われ、取得中もUIは操作可能な状態を維持する。

### 10.2 レスポンシブデザイン

デスクトップ（1024px以上）では2カラムレイアウト（左: 入力フォーム、右: 計算結果）を採用する。タブレット・モバイル（1024px未満）では1カラムに切り替わり、入力フォームが上、計算結果が下に配置される。

### 10.3 ブラウザ対応

Chromium系ブラウザ（Chrome・Edge）、Firefox、Safariの最新版に対応する。

### 10.4 データ永続化

サーバーサイドへの計算結果の保存は行わない。入力値はブラウザのメモリ上にのみ保持され、ページリロードでリセットされる。

### 10.5 セキュリティ

- eBay APIのクライアントID・シークレットはサーバーサイドにのみ保持し、フロントエンドには公開しない
- TTM取得はサーバーサイドのプロキシ経由で行い、外部サイトへの直接アクセスをフロントエンドから行わない

## 11. 前提条件と制約

1. **関税率は15%固定**: 日本原産品の相互関税率（Reciprocal Duty）を適用。送料早見表もこの税率で算出
2. **DDP対象は$2,500未満のみ**: $2,500以上はDDU選択可能（OC情報に基づく）
3. **Sales Taxはセラー負担なし（原則）**: eBayがMarketplace Facilitatorとして徴収・納付
4. **Sales TaxはeBay手数料ベースに影響**: Sales Tax込みの注文合計額に対してFVF等が課される
5. **為替レートはAPIで自動取得**: 三菱UFJ銀行公表の全営業日TTM（対顧客電信仲値）をAPIで取得し、前営業日のTTMを適用。土日祝の場合は直前の営業日のTTMが使用される
6. **消費税還付は輸出免税制度に基づく**: 国内仕入にかかる消費税が還付対象
7. **消費税率は10%固定**: 日本の標準税率
8. **TTM取得対象は前営業日**: 当日分は翌営業日に公表されるため
9. **早見表の上限は$2,499**: $2,500以上はDDU扱いで送料$0

## 12. 技術設計サマリー

### 12.1 技術スタック

| レイヤー | 技術 | 役割 |
|---|---|---|
| フロントエンド | React 19 + TypeScript 5.9 | UIレンダリング・型安全 |
| フロントエンド | Tailwind CSS 4 | スタイリング |
| フロントエンド | tRPC Client 11 + React Query 5 | API通信・サーバー状態管理 |
| バックエンド | Express 4 + tRPC Server 11 | HTTPサーバー・型安全RPC |
| ビルドツール | Vite / esbuild | フロント/バックエンドバンドル |
| テスト | Vitest 2.1 | ユニット・統合テスト |

### 12.2 システム構成

- フロントエンドとバックエンドは同一プロセスで動作
- 計算処理はすべてフロントエンドのメモリ上で完結（`useMemo` + 純粋関数 `calculate()`）
- バックエンドへのAPIリクエストはTTM取得（`exchangeRate.getTtm`）とeBay商品情報取得（`ebay.getItemInfo`）の2種類のみ
- 計算ロジックは `client/src/lib/calculator.ts` に純粋関数として実装（副作用なし）

### 12.3 ディレクトリ構成（主要ファイル）

```
ebay-profit-calculator/
```

## 13. 用語定義

| 用語 | 定義 |
|---|---|
| TTM | 対顧客電信仲値（Telegraphic Transfer Middle rate）。TTS（売レート）とTTB（買レート）の平均値 |
| DDP | Delivered Duty Paid。関税・送料を含む価格でバイヤーに届ける方式 |
| DDU | Delivered Duty Unpaid。関税はバイヤー負担の方式 |
| FVF | Final Value Fee。eBayが販売価格に対して課す手数料 |
| PL | Promoted Listings。eBayの有料広告プログラム |
| 方式B | 関税相当額を送料に上乗せして回収する価格設定方式 |
| 粗利 | 売上から仕入原価・手数料・送料を差し引いた利益（消費税還付前） |
| 還付込み利益 | 粗利に消費税還付額を加算した最終的な利益 |
| Sales Tax | 米国州売上税。eBayがMarketplace Facilitatorとして徴収・納付 |

## 14. 検算例

### 例1: 高単価商品（$3,970、送料$0）

| 項目 | 値 |
|------|-----|
| 販売価格 | $3,970 |
| 送料($) | $0 |
| 仕入価格 | ¥450,000 |
| 為替(USDJPY) | 159.7625 |
| Sales Tax | 5% |
| FVF | 12.35% |
| PL率 | 0% |
| 荷物分送料(¥) | ¥10,000 |

```
① 売上 = $3,970 × 159.7625 = ¥634,257

② eBay手数料
   手数料ベース = $3,970 × 1.05 = $4,168.50
   FVF      = $4,168.50 × 12.35% = $514.81
   海外手数料 = $4,168.50 × 1.35%  = $56.27
   PL       = $0
   eBay計   = $571.08

③ ペイオニア手数料（ネット基準）
   ネット受取 = $3,970 − $571.08 = $3,398.92
   ペイオニア = $3,398.92 × 2% = $67.98

④ 合計手数料(¥) = ($571.08 + $67.98) × 159.7625 = ¥102,098 ✓

⑤ 粗利 = ¥634,257 − ¥450,000 − ¥102,098 − ¥10,000 = ¥72,159 ✓
   粗利率 = ¥72,159 / ¥634,257 = 11.4% ✓
```

### 例2: 中単価商品（$467、送料$67）

| 項目 | 値 |
|------|-----|
| 商品価格 | $400 |
| 送料($) | $67（関税徴収用） |
| 販売価格(合計) | $467 |
| 仕入価格 | ¥40,000 |
| Sales Tax | 10% |
| FVF | 13.25% |
| PL率 | 3.0% |
| 荷物分送料(¥) | ¥3,000 |
| 関税徴収用送料(¥) | ¥10,760 |

```
① 売上 = $467 × 為替 = ¥74,662

② eBay手数料
   手数料ベース = $467 × 1.10 = $513.70
   FVF      = $513.70 × 13.25% = $68.07
   海外手数料 = $513.70 × 1.35%  = $6.94
   PL       = $513.70 × 3.0%   = $15.41
   eBay計   = $90.41

③ ペイオニア手数料（ネット基準）
   ネット受取 = $467 − $90.41 = $376.59
   ペイオニア = $376.59 × 2% = $7.53

④ 合計手数料(¥) = ($90.41 + $7.53) × 為替 = ¥15,659 ✓

⑤ 送料合計(¥) = ¥3,000 + ¥10,760 = ¥13,760

⑥ 粗利 = ¥74,662 − ¥40,000 − ¥15,659 − ¥13,760 = ¥5,243
   ※シート値: ¥5,244（¥1の丸め誤差）
   粗利率 = 7.0% ✓
```

## 付録: 計算フロー図

```
[必須入力]
  商品価格($), 仕入価格(¥)
    │
[推奨入力（デフォルト値あり）]
  PL率=3%, 荷物分送料=¥3,000, FVF%=12.35%
    │
[固定値]
  為替レート(TTM自動取得), SalesTax=5%, 海外手数料=1.35%, ペイオニア=2%
  送料($) ← 送料早見表から自動決定 or 手動入力
    │
    ├──→ 売上(¥) = (商品価格+送料) × 為替
    │
    ├──→ eBay手数料($) = (商品価格+送料) × (1+SalesTax%) × (FVF%+海外%+PL%)
    │
    ├──→ ペイオニア手数料($) = ((商品価格+送料) − eBay手数料) × 2%
    │
    ├──→ 合計手数料(¥) = (eBay手数料+ペイオニア手数料) × 為替
    │
    ├──→ 送料(¥) = 荷物分送料 + 関税徴収用送料
    │
    └──→ [粗利] = 売上 − 仕入 − 合計手数料 − 送料
              │
              ├──→ [還付込み利益] = 粗利 + 消費税還付額
              └──→ [還付込み利益率] = 還付込み利益 / 売上 × 100
```
