# eBay利益計算アプリ 機能・計算仕様書

文書更新日：2026-11-08

実装基準：2026-10-19、Manusチェックポイント `bcf2bec8`

実装コミット：`bcf2bec81820a2b899712541fd20d0b8503baa1c`

## 1. 対象と前提

日本からeBay USへ販売する商品の売上、手数料、梱包・保険込み送料、粗利、消費税還付参考額、還付込み利益を試算するWebアプリ。入力変更に合わせて結果を即時計算する。USD以外の通貨表示は参考換算であり、各国市場の手数料・税制を別に計算するものではない。

本書は上記コミットに実装されているユーザー確定の計算モデルを記載する。eBayの全カテゴリ・契約条件や税務上の還付可否を保証するものではない。Sales Tax 8%、手数料、保険条件、非適格仕入70%は現行モデルの設定値である。実取引・税務処理には個別の確認が必要。

計算対象のPLはPromoted Listingsの広告料。別途のPL保険（賠償責任保険等）は計算に含めない。日本側発送に加える輸送保険料とは区別する。

## 2. 入力・既定値

商品価格と仕入価格がともに正の場合に結果、履歴保存、CSV出力を利用できる。`calculate`自体は入力値から結果を返す関数であり、画面側がこの有効判定を行う。

| 広告自動判定 `useAutoPromotedListingRate` | 真偽値 | false | 有効時は3%で試算し、薄利なら0% |
| 仕入区分 `taxRefundEligibility` | `qualified` / `nonQualified` | `nonQualified` | 適格100%／非適格70% |

## 4. 売上とeBay手数料

Jを税込仕入価格（円）、XをUSD/JPY TTM、aを採用広告料率（%）とする。

```text
T = P + S                         # 受取総額（USD、Sales Taxを除く）
R = T × X                         # 売上（円）
B = T × 1.08                      # 手数料ベース（Sales Tax 8%込み）
FVF = min(B, 2500) × 0.1235 + max(0, B − 2500) × 0.0235
国際手数料 = B × 0.0135
広告料 = B × a / 100
固定費 = T >= 10.01 ? 0.40 : 0     # USD
E = (FVF + 国際手数料 + 広告料 + 固定費) × 1.10
ネット受取 = T − E
Payoneer = ネット受取 × 0.02
C = (E + Payoneer) × X             # 合計手数料（円）
```

FVFの境界は出品価格PではなくB=$2,500。eBay手数料の消費税10%は広告料・固定費にも加算する。Sales Tax自体はセラー売上Rへ加えず、手数料ベースにのみ含める。Volume割引は見込まない。固定費は常に$0.40ではなく、Tが$10.01以上のときに加算する現行実装を優先する。

## 5. 梱包・輸送保険込み送料（D）

```text
P < 800  : D = 4000
P >= 800 : D = ROUND(4000 + max(2500, P × X × 0.012))
買い手送料の同額費用 = S × X
送料合計 = D + S × X
```

$800ちょうどから輸送保険を計上する。保険金額は税込仕入額ではなく、商品価格Pの円換算。保険下限は¥2,500、料率は1.20%。手動送料モードでは`ROUND(max(0, 手動値))`をDに用い、自動計算値とは別に扱う。

## 6. 粗利と広告自動判定

```text
G = R − J − C − D − S × X
粗利率（%） = R > 0 ? G / R × 100 : 0
```

手動モードでは入力した広告料率のみを使用する。初期値は2%、0%なら広告なし。自動モードではまずa=3%でGと粗利率を計算する。粗利率が10%未満ならa=0%でeBay・Payoneer手数料と利益を再計算し、結果を採用する。10%以上なら3%を維持する。

この判定は還付額を加えない粗利率で行い、3%に手動料率を足さない。0%への再計算後に10%以上となっても再度3%へ戻さない。自動モードを解除すれば保持している手動入力値へ戻る。画面とCSVには採用された料率を表示する。

## 7. 消費税還付参考額と還付込み利益

```text
k = 適格請求書あり（qualified） ? 1.00 : 0.70
還付参考額 Q = J × 10 / 110 × k
還付込み利益 N = G + Q
還付込み利益率（%） = R > 0 ? N / R × 100 : 0
```

還付対象の基礎は仕入価格のみ。梱包・送料・輸送保険を加えない。メルカリ個人出品等を想定する非適格仕入が既定値で、選択により適格請求書ありへ切り替えられる。

非適格70%は、ユーザー確定仕様として「2026年10月以降」と表示する固定値である。取引日から80%・70%・50%等を自動選択する機能はなく、今後の制度・取引条件の変更には別途見直しが必要。適格区分の選択も証憑や還付適用要件を自動確認するものではない。

## 8. 利益フロア警告

```text
F = max(5000, ROUND(J × 0.03))
警告 = G < F
```

「¥5,000または仕入価格の3%の高い方」を必要最低利益として表示する。還付込み利益NではなくGで判断する。G=Fは警告対象ではない。

これは画面上の警告のみ。在庫監視の停止、eBay出品終了、仕入制限などの外部操作は行わない。

## 9. 為替取得・7日間キャッシュ

MURCの前営業日TTSとTTBを取得し、`ROUND((TTS + TTB) / 2, 小数2桁)`をTTMとする。エンドポイントは`https://www.murc-kawasesouba.jp/fx/past/index.php?id=YYMMDD`をGETで利用。Shift-JISをデコードする。

日本時間の前日から最大10暦日前までの候補日を遡り、土日は飛ばす。祝日カレンダーを持たず、データ取得不可ならさらに過去の日を試す。USDが取得できた最初の日を採用する。EUR・GBP・CAD・AUDも抽出可能なものを同時に返し、取得できない通貨は入力欄の既存値を維持する。

GBPは「英ポンド／イギリスポンド」、CAD・AUDは中点の有無を許容する。ページ初回表示で取得し、TTM再取得ボタンで更新できる。レートの手動入力は常に可能。

成功時はレート、データ日、取得元、保存時刻`cachedAt`をブラウザのlocalStorageへ保存する。取得失敗時は保存から7×24時間以内のキャッシュを利用し、キャッシュ利用中であることを表示する。ちょうど7日以内は有効、7日を超えるものや未来の保存時刻、無効なUSDレート等は不採用。期限はMURCデータ日ではなく保存時刻が基準である。

キャッシュは同じブラウザ・同じサイトの保存領域に限定される。手動入力値を取得済みTTMとして保存しない。初回失敗や期限切れで保存値を利用できない場合は、手動入力を促す。サーバー共有キャッシュや端末間同期はない。

## 10. 画面・比較・保存・出力

PCは入力と結果の2カラム、モバイルは縦積み。結果側は還付込み利益額、粗利額、両利益率、DDP/DDU、コスト内訳、手数料明細、利益フロアを表示する。利益サマリーの色は還付込み利益の正負に連動し、フロア警告は別表示する。

| 機能 | 現行の挙動 |
|---|---|
| 詳細パラメータ | 固定計算条件の説明を展開。FVF・Sales Tax等の編集入力はない |
| 多通貨表示 | USD価格×USD/JPY÷対象通貨/JPYでEUR・GBP・CAD・AUDへ参考換算。USDはDDP/DDUに連動し、その他はDDU前提 |
| ライバル比較 | 2件。商品価格＋送料を比較し最安値・価格差を表示。item numberから価格・送料・タイトルを取得可能、手動入力可 |
| 計算履歴 | 保存操作で最新を先頭に追加し最大10件。超過分は古いものから除外。個別削除・全削除可 |
| 履歴の保存内容 | ID、保存時刻、出品価格、仕入価格、買い手送料、売上、粗利、還付後利益 |
| 履歴の制限 | 広告モード・為替・仕入区分・フロア判定は未保存。保存済み入力の再読み込みはない |
| CSV | 現在の1計算を「項目,値」の2列で出力。UTF-8 BOM、CRLF、セルの引用符をエスケープ |
| リセット | 現在入力を既定値へ戻す。計算履歴とTTMキャッシュは削除しない |

CSVは出品価格、買い手送料、販売価格合計、仕入価格・区分、USD/JPY TTM、広告モード・採用料率、売上、eBay・Payoneer手数料、保険込送料、買い手送料実費、粗利・粗利率、還付率・還付額、粗利フロア、還付後利益を含む。履歴の一括CSVやライバルデータのCSVではない。

## 11. 丸めと境界

内部の売上・手数料・粗利・還付込み利益はJavaScriptの数値として保持し、費目ごとにUSD小数2桁へ丸めてから足す方式ではない。TTMは小数2桁、DとFは1円単位に丸める。円表示・CSVの円結果は`Math.round`、USD表示は小数2桁、画面の利益率は通常小数1桁、CSVは小数2桁。

広告自動判定と利益フロア判定は表示丸め前の値で行う。このため表示上¥5,000に見えても内部値がF未満なら警告となり得る。還付後利益は表示上の丸め済み粗利と還付額の足し算で再生成しない。

送料関数は小数USDに対応するが、現行メイン画面の商品価格等の`NumInput`は小数入力指定がなく整数として解析する。通常操作で小数価格を試算するための入力UI改善は未実施。この文書更新ではアプリコードを変更しない。
