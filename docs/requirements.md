文書更新日：2026-11-08。実装基準：**2026-11-08の2モード対応版**。

## 1. 対象と前提

日本から海外へ販売する商品の売上、手数料、梱包・輸送保険込み送料、粗利、消費税還付参考額、還付込み利益を即時計算するWebツール。販売モードはeBay US / CPASSと海外直接取引 / DHL直接契約。USD以外は参考換算であり、各国別の税・手数料を再計算するものではない。

定数・式はユーザー確定の試算モデルで、法令の現況、実際の徴収額、各サービスの契約条件、還付資格を保証しない。Sales Tax 8%、決済料率、保険条件、非適格70%等はモデルの設定値。取引日・制度改定による自動変更はない。

PLはPromoted Listings広告料を指す。PL保険（賠償責任保険等）は計算に含めず、日本側発送の輸送保険と区別する。archiveは履歴資料のみで、現行仕様の根拠に使用しない。

## 2. 入力・既定値

画面の結果・履歴保存・CSVの有効条件は商品価格と仕入価格がともに正数であること。`calculate`自体に包括的な入力検証はない。

| 入力 | 単位・値 | 既定値 | 用途 |
|---|---|---|---|
| `salesChannel` | `ebay` / `direct` | `ebay` | 販売モード |
| `directPaymentMethod` | `wise` / `revolut` / `paypal` | `wise` | 直接取引の決済方法 |
| `directDestination` | `hongKong` / `singapore` / `other` | `other` | DHL基本発送費の地域 |
| `directShippingUsd` | USD | 0 | 直接取引の請求送料。eBay手動値とは独立 |
| `itemPriceUsd` | USD、送料を除く商品価格P | 0 | 手数料・送料表・保険の基準 |
| `purchasePriceJpy` | 円、税込仕入J | 0 | 原価・還付・利益フロア |
| `promotedListingRate` | % | 2 | eBay手動広告料率。0は非出稿 |
| `useAutoPromotedListingRate` | 真偽値 | false | eBayのみ3%→粗利率10%未満なら0% |
| `taxRefundEligibility` | `qualified` / `nonQualified` | `nonQualified` | 両モード共通、適格100%／非適格70% |
| `useAutoShipping` | 真偽値 | true | eBay買い手請求送料の自動設定 |
| `manualShippingUsd` | USD | 0 | eBay自動送料無効時の値 |

| `manualDomesticShippingJpy` | 円 | 0 | 自動発送費無効時の値 |
| `exchangeRate` | USD/JPY、円/USD | 155 | TTM X、自動取得前の暫定値 |
| `exchangeRateEur`, `exchangeRateGbp` | EUR/JPY、GBP/JPY | 165、200 | 参考換算 |
| `exchangeRateCad`, `exchangeRateAud` | CAD/JPY、AUD/JPY | 110、100 | 参考換算 |

為替入力順序はUSD→EUR→GBP→CAD→AUD。非フォーカス時は3桁カンマ、為替は小数2桁表示。レートは手動変更可。直接請求送料は小数2桁入力、通常の商品価格・eBay手動送料・広告等は整数として解析する。

UIで異なる販売モードへ切り替えると`useAutoDomesticShipping=true`に戻し、送料表を閉じる。他の入力値は保持するが、各モードの計算対象だけを使用する。配送先変更だけでは手動発送費モードを解除しない。

左右は1本の昇順表を分割したもの。$100.50は$22、$149.01は$30、$800は$127、$2,499.99は$375、$2,500は$0。eBay手動では`manualShippingUsd`を使い、DDUでも0を強制しない。eBayのDDP/DDUラベルはPだけで決まる。

**直接取引**：価格・配送先を問わず全商品DDU。関税徴収用送料の自動加算はなく、S=`directShippingUsd`（既定$0）。`useAutoShipping`と`manualShippingUsd`は使わない。

両モードで売上にSを加える。eBayはS×Xを同額費用として差し引く。直接取引ではこの費用を0とし、請求送料を二重控除しない。実際のCPASS／DHL発送費Dは別途控除する。

## 4. 売上とモード別手数料

XをUSD/JPY TTM、aを採用広告料率（%）とする。両モード共通で`T=P+S`、`R=T×X`。

### 4.1 eBay

```text
B = T × 1.08                      # 手数料ベース、Sales Tax 8%込み
FVF = min(B, 2500)×0.1235 + max(0, B−2500)×0.0235
国際手数料 = B × 0.0135
広告料 = B × a / 100
固定費 = T >= 10.01 ? 0.40 : 0     # USD
E = (FVF + 国際手数料 + 広告料 + 固定費) × 1.10
ネット受取 = T − E
Payoneer = ネット受取 × 0.02
C = (E + Payoneer) × X             # 合計手数料（円）
```

FVF境界はPではなくB=$2,500。eBay手数料消費税10%は広告料・固定費にも加える。Sales Tax自体は売上Rに加えない。Volume割引は見込まず、直接決済手数料・適用直接決済率は0。

### 4.2 海外直接取引

```text
B = T                             # Sales Taxの上乗せなし
m = Wise 0.01 / Revolut 0.01 / PayPal 0.05
決済手数料 H = (P + directShippingUsd) × m
ネット受取 = T − H
C = H × X
```

FVF、国際手数料、Promoted Listings広告料、注文固定費、eBay手数料消費税、eBay合計手数料、Payoneerはすべて0。適用広告率も0%、`isAutoPromotedListingRate`と`wasPromotedListingDisabledByMargin`はfalse。保持中のeBay広告設定は影響しない。

## 5. 梱包・輸送保険込み発送費D

| 発送方法・地域 | 基本額L（円） |
|---|---:|
| eBay / CPASS | 5,000 |
| 直接 / DHL・香港 | 5,500 |
| 直接 / DHL・シンガポール | 5,500 |
| 直接 / DHL・その他 | 8,500 |

```text
P < 800  : D = L                  # 保険なし
P >= 800 : D = ROUND(L + max(2500, P × X × 0.012))
手動発送費 : D = ROUND(max(0, manualDomesticShippingJpy))
買い手送料の同額費用 K = eBay ? S × X : 0
送料合計 = D + K
```

全発送方法で$800ちょうどから保険を計上。基礎は送料を除く商品価格Pの円換算で、税込仕入額やTではない。下限¥2,500、料率1.20%。手動値は基本額・保険の内訳を別途足さずD全体を置換する。自動候補値も計算結果に保持する。

## 6. 粗利・広告自動判定

```text
G = R − J − C − D − K
粗利率（%） = R > 0 ? G / R × 100 : 0
```

eBay手動広告は既定2%、0%なら広告なし。任意の自動モードではまずa=3%で粗利率を試算し、10%未満ならa=0%でeBay・Payoneer・利益を一度再計算。10%以上なら3%を維持。判定に還付を含めず、手動率を足さず、0%で再計算後に3%へ戻さない。解除時は保持した手動率に戻る。直接取引ではこの判定を行わない。

## 7. 還付参考額・利益フロア（両モード共通）

```text
k = qualified ? 1.00 : 0.70
還付参考額 Q = J × 10 / 110 × k
還付込み利益 N = G + Q
還付込み利益率（%） = R > 0 ? N / R × 100 : 0
利益フロア F = max(5000, ROUND(J × 0.03))
警告 = G < F
```

還付基礎は仕入のみで、発送費・輸送保険・買い手請求送料は含めない。非適格70%はユーザー確定の固定モデルで、「2026年10月以降」というUI説明も法令の現況保証ではない。証憑確認・資格審査・取引日別料率自動切替はない。

フロアは未丸めの粗利で判断し、還付を含めない。G=Fなら警告なし。画面警告のみで、保存禁止、仕入制限、出品終了、在庫監視停止等の外部操作はない。

## 8. 為替取得・7日間キャッシュ

MURCの前営業日TTS/TTBから`ROUND((TTS+TTB)/2, 小数2桁)`を取得。既存の取得経路はGET `https://www.murc-kawasesouba.jp/fx/past/index.php?id=YYMMDD`、Shift-JIS復号。JST前日から最大10暦日前を遡り土日を除外、祝日カレンダーはなく取得不可ならさらに過去を試す。USD取得を成功条件とし、他4通貨の欠落は既存入力値を維持する。

初回表示・TTM再取得ボタンで通信する。成功時にrates、date、source、cachedAtを同じブラウザへ保存。失敗時のみ保存から7×24時間以内のキャッシュを利用し、その旨を表示する。7日ちょうどは有効、超過・未来保存時刻・無効なUSDは不採用。期限基準は相場日ではなく保存時刻。再利用で期限を延長しない。

手動レートは取得済みキャッシュとして保存しない。復元不能なら手動入力を促す。キャッシュは同一ブラウザ・同一サイト限定で、サーバー共有や端末間同期はない。

## 9. 画面・比較・履歴・CSV

PCは入力と結果の2カラム、モバイルは縦積み。名称・ブラウザタイトルは「海外販売利益計算ツール」。結果は販売モード、DDP/DDU、売上、費目、粗利・還付込み利益、両利益率、コスト内訳、フロア警告を表示する。利益サマリー色は還付込み利益の正負に連動。

| 機能 | 現行の挙動 |
|---|---|
| 詳細パラメータ | モード別固定条件の説明。固定料率編集は不可 |
| 多通貨表示 | 商品価格=P×X÷対象TTM。直接の販売価格=(P+S)×X÷対象TTM、すべてDDU |
| eBay多通貨 | USD販売価格はDDPでP+S、DDUでP。EUR/GBP/CAD/AUDはDDU商品価格のみ |
| ライバル比較 | eBayのみ2件。価格＋送料、最安値・差額。item number取得・手動修正可。直接では非表示 |
| 履歴 | 最新を先頭に最大10件、個別／全削除可。キー`ebay-profit-calculator.history.v1`を維持 |
| 新履歴の保存内容 | 従来のID・時刻・商品／仕入価格・請求送料・売上・粗利・還付後利益に、モード・直接決済／配送先・保険込送料・計算versionを追加 |
| 旧履歴 | モードなしは「eBay（旧計算）」。送料改定前の保存済み結果を維持し再計算しない |
| 履歴の制限 | 為替・仕入区分・広告モード・フロア判定等の全入力は未保存。完全入力再読み込み・再計算は未実装 |
| CSV | 共通`buildCalculationCsv`で現在の1件を「項目,値」の2列、UTF-8 BOM・CRLF・引用符エスケープ |
| リセット | `DEFAULT_INPUTS`へ戻す。履歴・ライバル・TTMキャッシュは削除せずTTM再取得もしない |

CSV名は`overseas-profit-{channel}-YYYY-MM-DD.csv`（channelは`ebay`または`direct`、日付はUTC）。ツール名・モード・発送方法・関税方式、直接のみ配送先・決済方法・率、価格・送料・合計、仕入区分・USD/JPY、広告、売上、各手数料、発送費モード・額、送料同額控除、粗利・還付・フロア・還付後利益を出力する。履歴一括CSV・CSVインポートはない。

## 10. 丸めと境界

売上・手数料・利益はJavaScriptの数値のまま保持し、費目別にUSD小数2桁へ丸めて足す方式ではない。TTMは小数2桁、DとFは1円単位。円表示・CSV結果は`Math.round`、USD表示は小数2桁、画面利益率は通常小数1桁、CSV粗利率は小数2桁。

広告判定・フロア判定は表示丸め前の値。表示上¥5,000でも内部値がF未満なら警告になり得る。Nは丸め済みGとQから再生成しない。送料関数は小数USD対応だが、通常の商品価格UIは整数解釈である。
